# CV Builder

A full-stack CV Builder web application built with **Next.js** that allows users to create and manage their professional CV information.

## Features

* User registration and login
* Dashboard for managing CV information
* Sections for Profile, About, Education, Experience, Skills, Projects, Awards, Leadership, Languages and Interests
* CRUD operations for CV data
* Dynamic CV preview based on saved user information

## Tech Stack

* Next.js
* React
* MongoDB & Mongoose
* JavaScript
* REST APIs
* JWT Authentication

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Purpose

Built to demonstrate full-stack development, authentication, database integration, REST APIs, CRUD operations, and dynamic user data management.
